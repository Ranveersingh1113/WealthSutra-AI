# Contributing to WealthSutra AI

## Branch naming
- Use purpose-driven names: `feature/<short-task>`, `fix/<short-task>`, `docs/<short-task>`, `chore/<short-task>`.
- Keep only `main` and active feature branches. Delete merged/obsolete branches.

## Issue → PR linkage (required)
Every pull request must:
- Link at least one issue in the PR body using `Closes #<issue-number>` or `Fixes #<issue-number>`.
- Include a clear purpose statement and scope.
- Include test evidence (logs, screenshots, or manual verification notes).

## Pull request hygiene
- Keep PRs focused and small.
- Close stale/superseded PRs with a clear maintainer comment that references replacement PR/commit.
- Ensure active PR branches are up to date with `main` before merge.

## Issue triage expectations
- Use labels consistently: `bug`, `frontend`, `backend`, `docs`, `security`.
- Close invalid/already-fixed issues with rationale and linked fix.
- Add assignee and milestone for active issues where applicable.
